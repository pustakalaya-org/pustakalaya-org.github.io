    Preface¶

    Hardware security is the foundation upon which all software security rests. Without trust in the hardware, no software guarantee can be meaningful. This book provides a comprehensive reference covering every major area of hardware security – from the most fundamental primitives (TPMs, PUFs, TRNGs) to cutting-edge developments in post-quantum cryptography and AI hardware security.

    Every chapter follows a rigorous structure: it begins with the threat landscape and motivating attack, explains the architecture with block diagrams, dives into both FPGA and ASIC implementations with real resource numbers, surveys every major commercial and open-source solution that exists today, walks through solved problems, and closes with exercises to test and deepen understanding.

    Who This Book Is For¶

    This book is intended for:

    • Hardware security engineers designing security into chips and systems

    • Software engineers building security systems on top of hardware primitives

    • Security researchers investigating hardware attack techniques and defenses

    • Students studying hardware security, embedded systems, or cryptography

    • CTF participants tackling hardware hacking challenges

    • Industry professionals in automotive, IoT, medical, aerospace, and telecom sectors

    What This Book Covers¶

    This book covers 36 hardware security technology areas organized into logical groups:

    Foundations (Chapters 1–5)
    TPM, HSM, PUF, TEE, and Hardware Root of Trust.
    Attack Defenses (Chapters 6–9)
    Side-channel attacks, hardware Trojan detection, secure boot, and TRNG.
    Platform Security (Chapters 10–14)
    FPGA security, IOMMU/DMA protection, memory security, anti-tamper, and attestation.
    Domain-Specific Security (Chapters 15–20)
    Automotive, PQC, JTAG debug, crypto accelerators, key management, and IoT.
    Authentication and Identity (Chapters 21–23)
    Secure elements, FIDO2/WebAuthn, and cryptocurrency wallets.
    Network and Architecture (Chapters 24–26)
    Network processors, CHERI capability hardware, and RISC-V security.
    Industry Solutions (Chapters 27–36)
    Formal verification, supply chain, 5G, medical, ICS/SCADA, biometrics, satellite, AI/ML, USB/Thunderbolt, and wireless.
    Emerging Technologies (Chapters 37–39)
    Confidential computing hardware (Intel TDX, AMD SEV-SNP, ARM CCA), hardware security design flow and EDA tools (from RTL to silicon), and chiplet and heterogeneous integration security (UCIe, DICE identity, HBM3 encryption).

    Conventions Used¶

    Each chapter uses:

    • TikZ block diagrams to visualise architectures

    • Code listings in C, Python, Verilog, assembly, and shell

    • Comparison tables for all existing solutions (FPGA LUTs, ASIC area, speed)

    • Solved Problems with step-by-step worked solutions

    • Exercises ranging from short-answer to open-ended design challenges

    • Note: Note boxes for important definitions and facts

    • Warning: Warning boxes for common mistakes and security pitfalls

    • Tip: Tip boxes for practical implementation advice
