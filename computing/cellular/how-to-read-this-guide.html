    How to read this guide¶

    Each topic follows the same simple pattern, so you can jump to any page and understand it without reading the rest first.

    How each topic is built¶

    In plain English
    A jargon-free explanation of what the topic is.
    Think of it like…
    An everyday analogy that makes the idea click.
    Real-world example
    A short realistic story or worked example showing it in action.
    How it works
    The key steps, in order.
    Who uses it
    The people, jobs and industries that rely on it.
    Key takeaway
    The single most important thing to remember.

    Many topics include a Try it box with a safe command or snippet. Then a table lists the most important entries — with what each one does and a concrete example.

    Entry type labels¶

    Concept, Standard, Release, Protocol, Interface, Network Function, Technology, Spectrum Band, Device, Equipment, Software, Tool, Service, Procedure, Metric, Regulation, Organisation, Certification, Career, Resource

    Concept = an idea to understand. Standard / Release = 3GPP, ITU and other official specifications and their versions. Protocol / Interface / Procedure = message exchanges and connections between network parts. Network function / Equipment / Device = parts of the network and the phones and modems that use it. Technology / Spectrum band = radio techniques and frequency ranges. Software / Tool / Service = things you install, run or buy. Metric = a measure. Regulation / Organisation / Certification / Career / Resource = rules, bodies, credentials, jobs and learning material.

    Status labels¶

    Current, Legacy, Emerging, Research

    Current = deployed and widely used. Legacy = older or being switched off. Emerging = standardised or just being deployed. Research = 6G and other ideas still in studies and labs.

    Generation labels¶

    1G, 2G, 3G, 4G, 5G, 5G-Advanced, 6G, All

    The mobile generation an entry mainly belongs to. All = applies across generations.

    About this guide¶

    This guide is for students and self-learners. Product names, versions, standards and dates were checked for accuracy as of late 2026, but cellular mobile networks changes quickly — confirm details with official documentation and standards bodies.
