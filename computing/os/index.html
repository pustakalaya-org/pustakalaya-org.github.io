    About this book¶

    A student's plain-English guide to operating systems — kernels, processes, memory, file systems, Linux, Windows, macOS, mobile, virtualization, containers and Kubernetes. Every topic is explained with an everyday analogy, a worked example, step-by-step mechanics, a diagram, and a table of the kernels, commands, tools, standards & concepts you need to know.
