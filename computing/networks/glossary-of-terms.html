    Glossary of Terms¶

    A¶

    Access point (AP)
    A device that connects Wi-Fi clients to a wired network.
    ACL (access control list)
    An ordered list of permit and deny rules that a router, switch or firewall checks top-down; anything unmatched is denied.
    ARP
    Address Resolution Protocol — finds the MAC address that belongs to an IPv4 address on the local network.
    AS (Autonomous System)
    A network or group of networks under one organisation's routing control, identified by an ASN.

    B¶

    Bandwidth
    The maximum amount of data a link can carry per second, e.g. 1 Gbps.
    BGP
    Border Gateway Protocol — the routing protocol that connects the networks of the Internet.
    Broadcast domain
    The set of devices that receive each other's broadcast frames; routers and VLANs separate them.

    C¶

    CIDR
    Classless Inter-Domain Routing — writing networks as address/prefix, e.g. 10.0.0.0/8.
    Collision domain
    A segment where frames can collide; each switch port is its own collision domain.

    D¶

    Default gateway
    The router a device sends traffic to when the destination is on another network.
    DHCP
    Dynamic Host Configuration Protocol — automatically gives devices an IP address, gateway and DNS server.
    DMZ (screened subnet)
    A separate firewall zone for Internet-facing servers, keeping them apart from the internal network.
    DNS
    Domain Name System — translates names like example.com into IP addresses.
    Dual stack
    Running IPv4 and IPv6 side by side on the same hosts and routers during the move to IPv6.

    E¶

    Encapsulation
    Wrapping data with headers at each layer as it travels down the network stack.
    Ethernet
    The IEEE 802.3 family of wired LAN technologies.

    F¶

    Firewall
    A device or software that allows or blocks traffic based on rules.
    Frame
    The Layer 2 unit of data, containing MAC addresses.
    Full duplex
    Sending and receiving at the same time, like a phone call.

    G¶

    Gateway
    A device that connects two different networks, often meaning the default router.

    H¶

    Hop
    One step of a packet's journey from one router to the next.
    Host
    Any device with an IP address — a computer, phone, server or printer.
    HTTP / HTTPS
    The protocol of the web; HTTPS is HTTP protected by TLS encryption.

    I¶

    ICMP
    Internet Control Message Protocol — carries error and diagnostic messages; used by ping and traceroute.
    IP address
    A logical address that identifies a device on an IP network (IPv4: 32 bits, IPv6: 128 bits).
    IPsec
    A suite of protocols (IKE, ESP, AH) that authenticates and encrypts IP packets; the usual basis of site-to-site VPNs.
    IPv6
    The newer Internet Protocol with 128-bit addresses, created because IPv4 addresses ran out.
    ISP
    Internet Service Provider — the company that connects you to the Internet.

    J¶

    Jitter
    Variation in delay between packets; bad for voice and video calls.

    L¶

    LAN
    Local Area Network — a network in one home, office or building.
    Latency
    The time it takes for data to travel from source to destination, usually in milliseconds.
    Load balancer
    A device or service that spreads traffic across several servers.
    Loopback
    A special address (127.0.0.1 or ::1) that always means 'this device itself'.

    M¶

    MAC address
    A 48-bit hardware address of a network interface, e.g. 3C:22:FB:12:34:56.
    Modem
    Converts between the provider's line signal (cable, DSL, fiber) and Ethernet.
    MPLS
    Multiprotocol Label Switching — forwards packets using short labels; common in provider WANs.
    MTU
    Maximum Transmission Unit — the largest packet size a link can carry, typically 1500 bytes on Ethernet.

    N¶

    NAC (network access control)
    Checking who and what a device is, usually with 802.1X and RADIUS, before letting it onto the network.
    NAT
    Network Address Translation — lets many private addresses share one public IP address.

    O¶

    OSI model
    A 7-layer reference model describing how network communication is organised.
    OSPF
    Open Shortest Path First — a link-state routing protocol used inside organisations.

    P¶

    Packet
    The Layer 3 unit of data, containing source and destination IP addresses.
    Packet loss
    Packets that never arrive, caused by congestion, errors or faulty links.
    Port (logical)
    A number (0-65535) that identifies an application on a host, e.g. 443 for HTTPS.
    Port (physical)
    A socket on a device where a cable plugs in.
    Protocol
    An agreed set of rules for how devices communicate.

    Q¶

    QoS
    Quality of Service — giving priority to important traffic such as voice.

    R¶

    RFC
    Request for Comments — the official documents that define Internet standards, published by the IETF.
    Router
    A Layer 3 device that forwards packets between different networks.
    Routing table
    The router's list of known networks and where to send packets for each.

    S¶

    SASE
    Secure Access Service Edge — SD-WAN combined with cloud-delivered security such as web filtering, ZTNA and firewalling.
    SDN
    Software-Defined Networking — controlling the network centrally with software.
    SD-WAN
    Software-Defined WAN — a centrally managed overlay that steers each application over the best of several WAN links.
    Segment
    The Layer 4 unit of data in TCP (in UDP it is called a datagram).
    Socket
    The combination of IP address, port and protocol that identifies one end of a connection.
    Subnet
    A smaller network carved out of a larger IP address block.
    Subnet mask
    Shows which part of an IP address is the network, e.g. 255.255.255.0 = /24.
    Switch
    A Layer 2 device that forwards frames to the right port using MAC addresses.

    T¶

    TCP
    Transmission Control Protocol — reliable, ordered, connection-based delivery.
    Throughput
    The actual amount of data successfully transferred per second.
    TLS
    Transport Layer Security — encrypts data in transit; the padlock in your browser.
    Topology
    The layout of a network: star, mesh, bus, ring and so on.
    TTL
    Time To Live — a hop counter in each IP packet that stops packets looping forever.

    U¶

    UDP
    User Datagram Protocol — fast, connectionless delivery without guarantees.

    V¶

    VLAN
    Virtual LAN — splits one physical switch into separate logical networks.
    VPN
    Virtual Private Network — an encrypted tunnel across another network.

    W¶

    WAN
    Wide Area Network — connects networks across cities, countries or continents.
    Wi-Fi
    Wireless LAN technology based on the IEEE 802.11 standards.

    Z¶

    Zero trust
    A security model that never trusts a device for being 'inside'; every request is checked by identity, device health and context.
