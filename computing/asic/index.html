    About this book¶

    A student's plain-English guide to how a digital chip goes from an idea to manufactured silicon — flow, concepts, tools, file formats, standards, companies and careers. Every topic is explained with an everyday analogy, a worked example, step-by-step mechanics, and a table of the concepts, tools (commercial and open source), file formats, standards and companies you need to know.
